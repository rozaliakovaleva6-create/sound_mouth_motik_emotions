# Инструкция: звуковая архитектура

## 1. Схема звуковой системы

```
┌──────────────────────────────────────────────────────────────────────┐
│ ИСТОЧНИКИ ЗВУКА                                                       │
├──────────────────────────────────────────────────────────────────────┤
│ 1. Ручная команда:                                                    │
│    rosservice call /oled_mouth/play_audio "data: 'файл.mp3'"         │
│                                                                      │
│ 2. Топик:                                                            │
│    rostopic pub /oled_mouth/audio_path std_msgs/String "data: '...'" │
│                                                                      │
│ 3. Программный вызов (Python):                                       │
│    from ainex_sdk import voice_play                                   │
│    voice_play.play('running')                                        │
│                                                                      │
│ 4. Остановка:                                                        │
│    rosservice call /oled_mouth/play_audio "data: 'stop'"             │
└─────────────────────────┬────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────────────────┐
│ robot_mouth_talk_node                                                 │
├──────────────────────────────────────────────────────────────────────┤
│ 1. Ищет файл:                                                        │
│    voice/ → ainex_sdk/audio/ → /home/ubuntu/Music/                   │
│                                                                      │
│ 2. Воспроизводит:                                                    │
│    pygame.mixer (предпочтительно) или aplay/mpv/ffplay               │
│                                                                      │
│ 3. Анализирует RMS (громкость) для анимации рта                      │
│                                                                      │
│ 4. Публикует /audio/playback_level (Float32: 0..1)                   │
│                                                                      │
│ 5. Рисует осциллограмму на OLED 0x3D (если active_driver=mouth)      │
└──────────────────────────────────────────────────────────────────────┘
                          │
              ┌───────────┼───────────┐
              ▼           ▼           ▼
         Динамики    OLED 0x3D    /audio/
         (ALSA)    (осциллограмма) playback_level
```

## 3. Команды

### Воспроизвести файл

```bash
# По имени (ищет в voice/)
rosservice call /oled_mouth/play_audio "data: 'adam-dragon-us_3475244.mp3'"

# По полному пути
rosservice call /oled_mouth/play_audio "data: '/home/ubuntu/Music/song.mp3'"

# Через топик
rostopic pub --once /oled_mouth/audio_path std_msgs/String "data: 'countdown-on-device.mp3'"
```

### Остановить воспроизведение

```bash
rosservice call /oled_mouth/play_audio "data: 'stop'"
```

Допустимые значения для остановки: `stop`, `halt`, `q`, `quit`.

### Список доступных файлов

```bash
ls /home/ubuntu/ros_ws/src/sound_mouth_motik_emotions/voice/
```

### Добавить новый файл

```bash
cp /путь/к/файлу.mp3 /home/ubuntu/ros_ws/src/sound_mouth_motik_emotions/voice/
# Сразу доступен для воспроизведения:
rosservice call /oled_mouth/play_audio "data: 'файлу.mp3'"
```

## 4. Форматы

| Формат | Воспроизведение | Анимация (RMS) |
|--------|----------------|----------------|
| WAV | pygame / aplay | soundfile (numpy) |
| MP3 | pygame / mpv / ffplay | pydub → numpy |

Для MP3 рекомендуется установить `pydub` и `ffmpeg`:
```bash
pip3 install pydub
sudo apt install ffmpeg
```

## 5. Устройство вывода звука

```bash
# Список устройств
aplay -l

# Проверка громкости
amixer sget Master

# Тестовый звук
speaker-test -t wav -c 1

# Запуск с конкретным устройством
roslaunch sound_mouth_motik_emotions display_3d.launch output_device:=plughw:2,0
```

## 6. Анимация рта по звуку

Во время воспроизведения:
1. Нода загружает аудио файл в память (soundfile/pydub)
2. Считает RMS (среднеквадратичное значение) в окне 40мс
3. Масштабирует: `level = min(1.0, rms * 32.0)`
4. Публикует в `/audio/playback_level`
5. Рисует `draw_mouth_mode7(level)` на OLED 0x3D

Когда нет воспроизведения:
- Слушает `/audio/mouth_open_level` от внешней ноды (микрофон/динамик)
- Если данные не приходят — статичный рот

## 7. Программный вызов из Python

```python
import rospy
from ainex_interfaces.srv import SetString

rospy.wait_for_service('/oled_mouth/play_audio')
play = rospy.ServiceProxy('/oled_mouth/play_audio', SetString)

# Воспроизвести
play('adam-dragon-us_3475244.mp3')

# Остановить
play('stop')
```

## 8. Устранение проблем

| Проблема | Проверка |
|----------|----------|
| Нет звука | `aplay -l`, `amixer sget Master`, `speaker-test -t wav` |
| pygame ошибка | `export SDL_VIDEODRIVER=dummy; export SDL_AUDIODRIVER=alsa` |
| Файл не найден | Проверить `ls voice/`, указать полный путь |
| RMS не работает (плоский рот при звуке) | `pip3 install numpy soundfile pydub` и `sudo apt install ffmpeg` (scipy для RMS **не нужен**) |
| Сервис не найден | `rosservice list \| grep oled_mouth` — нода не запущена |
